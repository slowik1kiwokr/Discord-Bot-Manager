✨ ÚJ FUNKCIÓK:

  📌  Integrációs panel — teljes újratervezés
      • „Van már botod?" választó (2 ág)
      • Meglévő bothoz: csak panel_integrity.py hozzáadása
      • Új bothoz: teljes 3 fájlos sablon generálás
      • Fájlok száma 5-ről 3-ra csökkent:
          - bot.py
          - panel_integrity.py (minden panel funkció)
          - version.py
      • Függőségek ablak a fejlécben
      • Bot adatai gomb a token beállításához

  ⚡  Commander — teljes újratervezés
      • Bot mappa fájlfa (mint VSCode)
      • Fájl szerkesztő beépítve
      • Új fájl / mappa létrehozás
      • Átnevezés / törlés
      • 18 parancs sablon
      • Részletes parancs szerkesztő (embed szín, footer, thumbnail)
      • Élő szín előnézet + gyors színek
      • Extension lista (bot_extensions.txt)
      • Auto-extension: új .py fájl automatikusan betöltődik
      • Python szintaxis ellenőrzés mentés előtt

  📢  Broadcast — teljes újratervezés
      • Automatikus szerver + csatorna lista (bot_channels.json)
      • Csatorna jogosultság jelző:
          - 🚫 = bot nem tud írni
          - ⚠️ = bot nem tud embedet küldeni
      • 8 broadcast sablon
      • Embed támogatás (cím, leírás, szín, footer, thumbnail)
      • Időzített küldés (1 perc – 24 óra)
      • Élő előnézet (Discord-szerű megjelenés)
      • Csatorna gyorsválasztó (Összes / Egyik sem)

  🔤  Bot prefix támogatás
      • BOT_PREFIX a version.py fájlban
      • Prefix mező a Bot adatai ablakban
      • bot.py: get_prefix() függvény
      • Állítható: / ! ? $ stb.

  🔌  panel_integrity.py — minden egy fájlban
      • /connect parancs
      • Statisztika küldés a panelnek
      • Csatorna lista küldés
      • Távoli vezérlés (start / stop / restart / info / log / stressz)
      • Broadcast (embed + időzítés támogatás)
      • Commander parancsok betöltése
      • Auto-extension-ök betöltése
