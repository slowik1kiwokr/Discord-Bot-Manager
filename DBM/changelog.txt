🔗 LAN PANEL ÖSSZEKÖTTETÉS (ÚJ)
  • Host mód — az egyik gépen futó botok vezérelhetők a másikról
  • Kliens mód — csatlakozás távoli panelhez IP + port + token segítségével
  • HTTP alapú kommunikáció a helyi hálózaton (LAN)
  • Token-alapú hitelesítés (32 karakteres, generálható)
  • Távoli vezérlés engedélyezése / letiltása (csak olvasás mód)
  • Bot kártyák a kliens ablakban (állapot, RAM, CPU, hibák)
  • Indítás / újraindítás / leállítás egy kattintással
  • Kapcsolódási naplók (sikeres / sikertelen műveletek)
  • Cache-elés — host offline esetén is látszik az utolsó állapot
